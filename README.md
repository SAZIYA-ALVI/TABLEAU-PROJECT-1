Depression Student Analysis Dashboard

📊 Project Overview

This project is a Depression Student Analysis Dashboard based on a student dataset. The dashboard analyzes different academic, lifestyle, and stress-related factors and their distribution among students.

The main purpose of this project is to understand student patterns using data analysis and visualization.

🎯 Objectives

Analyze student count based on Sleep Duration.

Analyze student count based on Study Hours.

Analyze Study Satisfaction levels.

Analyze Academic Pressure levels.

Analyze Financial Stress levels.

Present the findings through an interactive and easy-to-understand dashboard.

📌 Dashboard Analysis

1. Sleep Duration vs Student Count

This section analyzes how students are distributed according to their sleep duration:

Less than 5 hours

5–6 hours

7–8 hours

More than 8 hours

2. Study Hours vs Student Count

This visualization shows the number of students according to their daily study hours and helps identify the distribution of study time among students.

3. Study Satisfaction vs Student Count

This section analyzes student satisfaction levels, ranging from lower to higher satisfaction levels.

4. Academic Pressure vs Student Count

This visualization shows the distribution of students across different academic-pressure levels.

5. Financial Stress vs Student Count

This section analyzes the financial-stress levels reported in the student dataset.

🔍 Key Insights

The dashboard provides an overview of important student-related factors, including:

Sleep duration

Study habits

Study satisfaction

Academic pressure

Financial stress

These factors can be explored together to understand patterns in the student population and support further analysis of student depression-related data.

Note: The dashboard shows distributions and relationships in the dataset. It should not be interpreted as proving that any individual factor directly causes depression.
